บันทึกกิจกรรม (เข้าสู่ระบบ · คำสั่งซื้อ · การชำระเงิน · การตั้งค่า) เป็นไฟล์ใน Drive
เป็นโหมดเสริมสำหรับ production — การติดตั้งใหม่จะปิดไว้โดยค่าเริ่มต้น
เมื่อเปิดใช้งาน ระบบจะบันทึก hash ของผู้ใช้/เซสชัน · user agent · ข้อมูลกิจกรรม ลงโฟลเดอร์ /log ใน Drive (เก็บ 90 วัน) — โฟลเดอร์นี้เป็นข้อมูลส่วนบุคคล ควรเก็บเป็นส่วนตัว
การเก็บ IP จะให้เบราว์เซอร์ของลูกค้าดึง IP สาธารณะจาก ipify แล้วส่งกลับมา — เป็น IP ที่ลูกค้าดึงเอง ไม่ใช่ IP ที่เซิร์ฟเวอร์ตรวจสอบ และมีการส่งข้อมูลให้บริการภายนอก แนะนำให้เปิดเฉพาะเมื่อจำเป็น
